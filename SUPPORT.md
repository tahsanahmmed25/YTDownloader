# Support

For usage problems, open a GitHub issue with:

- YTDownloaderPro version
- Operating system and architecture
- Whether you used Normal Mode or Restricted Mode
- Whether yt-dlp/FFmpeg were system-installed or app-managed
- The privacy-safe log excerpt from the app log

Do not attach cookies, session files, proxy URLs with passwords, or private video links. Redact account identifiers before sharing logs.

For security issues, use `SECURITY.md` instead of a public issue.
