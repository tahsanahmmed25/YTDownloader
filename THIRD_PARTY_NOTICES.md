# Third-Party Notices

YTDownloader depends on third-party software. Review each upstream license before redistribution.

- PySide6 / Qt for the desktop UI
- requests for HTTP requests
- browser-cookie3 for local browser cookie extraction
- yt-dlp for media metadata extraction and downloads
- FFmpeg / FFprobe for media muxing and conversion
- keyring, SecretStorage, jeepney, and cryptography for OS credential integration
- PyInstaller and Inno Setup for packaging
- AppImageKit appimagetool for Linux AppImage creation

Release builds should include third-party license notices appropriate to the packaged artifacts and platform.
